# Student Login Task

PHP task using XAMPP, MySQL, PDO, sessions, login, register, logout, and profile page.

## Run

1. Copy the project folder to `C:\xampp\htdocs`.
2. Start Apache and MySQL from XAMPP.
3. Import `database.sql` in phpMyAdmin.
4. Open:

```text
http://localhost/atsk2_Nti_user_login_php/login.php
```
